# 🌿 Portfólio Ambiental – Fatec Itu

Link do Projeto: https://projeto-ihc-green.vercel.app/index.html

Bem-vindo ao nosso Portfólio Ambiental, desenvolvido para a disciplina de Interação Humano-Computador (IHC) da Fatec Itu em comemoração ao Dia Mundial do Meio Ambiente.

## 🎯 Objetivo do Projeto

Este site foi criado com o propósito de valorizar a biodiversidade presente no campus da Fatec Itu e em seu entorno, promovendo a conscientização ambiental por meio da fotografia. As imagens expostas foram registradas pelos integrantes da equipe e retratam elementos da fauna, flora e paisagens naturais da região.

## 🚀 Como rodar o projeto no seu computador
⚠️ **Aviso importante:** Nosso site usa funções do javascript que são bloquedas pelos navegadores se o projeto for rodar localmente, abrir o arquivo `index.html` direto da pasta (com dois cliques) pode fazer com que os navegadores bloqueiem essas funções por segurança.
**Para rodar localmente de forma perfeita:** Abra a pasta do projeto no VS Code e inicie o site utilizando a extensão **Live Server** (ou qualquer outro servidor local de sua preferência).

## 💻 Tecnologias Utilizadas

O projeto foi desenvolvido utilizando tecnologias web leves e compatíveis com hospedagem compartilhada, garantindo bom desempenho e acessibilidade.

* **HTML5** – Estruturação do conteúdo e das páginas.
* **CSS3** – Estilização da interface.
* **JavaScript** – Implementação de funcionalidades interativas, como filtros da galeria e animações da navegação.
* **Google Fonts** – Utilização das fontes *Playfair Display* e *Lato*.

## 🧠 Decisões de Design e Interação Humano-Computador (IHC)

Durante o desenvolvimento, foram aplicados conceitos de usabilidade, acessibilidade e experiência do usuário:

### Identidade Visual

Optamos por um tema predominantemente escuro, utilizando o preto e um tom de verde escuro como cor de fundo principal. Essa escolha foi feita para destacar as fotografias e valorizar as cores naturais presentes nas imagens, criando maior contraste visual e direcionando a atenção do usuário para os elementos ambientais registrados.


### Organização da Galeria

A galeria foi projetada para apresentar as imagens de forma limpa e organizada. Ao selecionar uma fotografia, o usuário pode visualizar informações complementares, como descrição, equipamento utilizado, data e local do registro, sem precisar sair da página atual.

### Feedback Visual

Foram implementadas animações suaves, efeitos de transição e interações visuais que auxiliam o usuário a compreender as ações realizadas no sistema.

## 🧭 Instruções de Navegação

### Página Inicial

Apresenta uma introdução ao projeto e ao Dia Mundial do Meio Ambiente, intercalando textos e imagens para proporcionar uma experiência visual agradável.

### Galeria

Reúne as fotografias produzidas pela equipe. O usuário pode utilizar os filtros disponíveis para visualizar categorias específicas, como fauna, flora e paisagens.

### Sobre

Contém informações sobre o projeto e seus integrantes. Os conteúdos são organizados em seções expansíveis, permitindo acesso rápido às informações de cada membro da equipe.

## ♿ Acessibilidade

Para garantir uma experiência mais inclusiva, foram adotadas as seguintes práticas:

* Contraste adequado entre texto e fundo;
* Tipografia legível e tamanho de fonte apropriado;
* Navegação clara e consistente;
* Compatibilidade com diferentes tamanhos de tela.
